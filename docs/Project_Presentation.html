🎯 Executive Summary

Event-Connect replaces manual Microsoft Forms + Excel spreadsheets with a scalable, production-grade AWS serverless REST API and a modern web dashboard. The system automates capacity control, eliminates duplicate sign-ups, dispatches instant SNS email confirmations, and connects seamlessly to multiple student API Gateways across AWS regions.

🏛️ System Architecture & AWS Services Used

  • AWS API Gateway: REST API router supporting CORS, stage normalization, and HTTP routing.
  • AWS Lambda (Python 3.12): Serverless functions handling event listings, sign-ups, ticket queries, and cancellations.
  • Amazon DynamoDB: Pay-per-request tables (EventsTable and RegistrationsTable with EmailIndex GSI).
  • Amazon SNS: Confirmation topic publishing instant email receipts to participants.
  • Amazon CloudWatch: 14-day log group retention + RegisterErrorRateAlarm (>5% threshold).
  • GitHub Actions CI/CD: Automated testing on pull request + automated SAM deployment on push to main branch.

🛠️ REST API Endpoints Overview

GET /events # Returns all events & live attendee counts POST /register # Creates registration & sends SNS notification GET /registrations/{email} # Fetches registrations by email GET /registrations/all # Fetches all confirmed registrations DELETE /registration/{id} # Cancels a ticket & restores seat capacity
